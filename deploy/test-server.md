本文件记录测试服务器的非敏感连接信息，供 [docker-deploy](../codex/skills/docker-deploy/SKILL.md) 使用。服务器信息不代表授权立即部署，也不代替网络访问权限。

- 服务器：`1.117.58.239`（腾讯云测试环境）。
- SSH 端口：默认 `22`，尚未连接核实。
- 用户名：`root`。
- 连接方式：用户要求部署到本测试环境时，通过执行者本机 PowerShell 调用 SSH。
- 认证凭据：由执行者通过受控配置或凭据管理工具提供，不在本文件、Skill 或 Git 中保存密码、私钥或其他认证凭据；缺少凭据时先补齐，不自行猜测。
- 访问白名单：服务器配置了 SSH 访问白名单，成员能否连接取决于实际网络权限。操作只限本次指定项目，不能据此默认清库、重装或影响其他项目。

派生项目使用其他服务器时，更新本文件或在项目上下文中另行记录。
